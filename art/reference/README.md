# FLUX visual reference baseline

The user-supplied
[`flux-champions-visual-style-v1.png`](../../assets/concept/flux-champions-visual-style-v1.png)
is the minimum style and expression baseline for the visual-production v3
pipeline. It is a 1536 x 1024 RGBA PNG with SHA-256
`cb8aa1b3f4e1c41498a35dd37303a3783b0f8fa2c0bbb0b75a89cbd02934732f`.

The pictured eighteen champions establish the mandatory bar for compact
proportions, expressive silhouettes, readable equipment/materials, ancestry
shape language, and elemental personality. The board is a `concept_reference`,
not a frame sheet or content authority; production creates original, aligned
sprites for every required direction and action.

Explicit current project decisions override details visible in the sheet,
including darker-skinned S. Wayne, red-skinned Steezo, male dark-haired Spai Si,
short dark-haired Haara, canonical race/name data, and the distinction between
current `dark` terminology and legacy `void`.

The board depicts Oh Tipi, S. Wayne, The Red Baron, Steezo, Treevor the Mason,
Oll' I, Fluup, Wa Bidi, Nico Lai, Spai Si, Leaf the Hidden, Ha Rekt, Dr. Apex,
Haara, Hesus Christo, Grimm Bow, Biggy Bob, and Jan Wicked. Board labels do not
override canonical ancestry, element, spelling, roster, balance, or lore data.
