# Visual slice authority boundary

`nexus_to_conservatory_visual_v1.json` is a presentation layout for tile review,
landmarks and route communication. It is not a replacement for the authoritative
Sanctum map package.

Before G2 promotion, the same slice still requires reviewed worldbone topology,
elevation bands, collision, material seeds, reset groups, navigation/safety
metadata, measured ordinary and advanced routes, cutaway geometry and platform
acceptance.
