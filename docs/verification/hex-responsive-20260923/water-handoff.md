Practice/base mode retains all geometry for stone rendering. The definite repeated work is `view()` calling `render_regions()` for all 44 layers of every selected cell, followed by `_collect_render_regions()` scanning those same cell/layer pairs and querying each present pair again. For N selected cells and P present pairs this is 44N + P region queries, before region validation and drawing.

Smallest promising change: an optional synchronous, stateless authority method returning the exact legacy view dictionary plus its raw regions from one traversal. Skip a layer only when its existing `cells[cell][material]` dictionary has no entries; never skip because summed quantity is zero. This avoids duplicating phase/provenance rules in presentation and does not need a persistent render cache.
