## Proportion correction still required

The runtime already uses fixed 58/63/68px declared neutral heights and shared
registration. Some painted low/air keys shrink facial or torso landmarks more
than the pose warrants; H. Lenee and S. Wayne are clear examples. Correct those
drawings against each identity's idle landmarks, without whole-sprite stretching,
changing collision or reintroducing mesh morphing. Compare front and profile,
then all eight headings and continuous transitions before expanding to the cast.

An image-generated H. Lenee action-atlas trial changed output dimensions and
pixel/facial detail, so it was **rejected and never integrated**. Its prompt and
reason are retained in [trial provenance](../reference/art/portraits_20261008/action-anatomy-trial.json).
No production body-atlas PNG was changed in this checkpoint. Complete authored
slide/roll/flight/strafe/air-cast cycles remain future artwork, not test-proven work.
