# Garden attribution: evidence, no runtime change

Four launcher-driven native processes passed **3,131 checks each**, with exact paired pixels, authority and lifecycle outcomes, empty stderr and complete viewport cleanup. The [independent numerical readback](analysis/readback-a.json) passed 22,791 checks; [Experience's independent analysis](analysis/experience-independent-analysis-a.json) agrees. The root invoked the desktop wrapper for each process; this is not evidence of a physical shortcut click or a focused whole-game test.

All four processes use 25 visible plots at (4736, 1152), a 1280 x 720 viewport, normal/reduced effects and opposite invocation orders. Each completes 144 exhibition evolution steps plus departure, reaches one expiry and one restart, and performs no product-pulse mutation. Fifty staged arrival frames preserve one exhibit emission and one visual preparation per frame. Both presentation geometry dictionaries are empty after departure; both viewport owners close.

The prior captured state is tick 27 and the first-expiry-labeled state is tick 117. Twenty-three plots move from forming to active and one from active to resetting between those captures. Sparse phase captures therefore cannot establish the frequency or grouping of continuously drawn phase-refresh work. Invocation order also changes apparent observer overhead substantially.

These are elapsed native method intervals, not thread CPU counters, GPU/present latency, portable FPS or player-feel acceptance. Matching Profile B's plot count and location does not match its full application load, authority age or callback history. No geometry cache or production optimization follows from this archive.
