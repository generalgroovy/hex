# Ground-speed call-local reuse — withdrawn

The candidate reused one identical integer ground-speed projection inside a single movement call. It remains unapplied. The reverse native process missed both predeclared selection thresholds: at least 1% and 10 microseconds per completed-step paired median saving in each process. There is no canonical performance gain to report.

| Positive measured groups / completed steps | 48 / 216 | 48 / 216 |
| Paired median saving per step | 16.4375 µs | 6.0625 µs |
| Median paired fractional saving | 1.4649% | 0.6880% |
| One-step median saving | 24 µs | −1.5 µs |
| Eight-step median saving per step | 11.0625 µs | 11.125 µs |
| Reference-first mean saving per step | 28.9271 µs | 32.7031 µs |
| Candidate-first mean saving per step | −6.3177 µs | −21.6667 µs |

Positive numbers mean a saving. Invocation-order mean signs reverse in both processes. All outliers, warmups, zero-step groups and verification tails remain in the raw receipts and analysis. Only one measured group per process contains an admission and one contains a release, so these rows do not establish reliable active-casting tails.

The prepared identity gate passed 2,542 checks across 300 controls. The ordinary finite Fire route passed 5,145 checks over 240 ticks, with two paid admissions, two releases, no refusals, actual flight and ground, and 1,200 matter paid. Both native order runs passed 3,958 checks. The independent analysis passed 3,739 checks; Technical separately reported 2,448 checks and agreed with withdrawal.

The complete functional trajectory compares every tick. Cost runs execute continuous 0/1/8 groups, preserve every command and ordered event against that qualified trace, and compare strict state/packet/payment at group boundaries. No interior timing-state snapshot or whole-game/FPS inference is claimed. The experiment stops here: no idle/Mantle expansion or production edit.
