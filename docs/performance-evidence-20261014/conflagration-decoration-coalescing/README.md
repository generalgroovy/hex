# Conflagration decoration coalescing — withdrawn

The Low-detail candidate is **WITHDRAWN**. Only one of four predeclared primary cost gates passed, and the unchanged single-product control repeatedly regressed beyond both rejection thresholds. Nothing from this experiment was applied to canonical rendering. The separately retained stationary-movement change is outside this archive.

Both complete native processes passed 7,459 checks over 15 contexts, plus 91 prepared-control checks each. Their 60 PNGs, source inventories, actual callback order, paid outcomes and cleanup were independently checked. Each process contains 192 measured pairs, 24 warmup pairs and nine pixel-only pairs. All 338 source inputs were reread before root applied the separate movement change; that [temporal source record](final-source-readback.json) must not be mistaken for verification of the subsequently edited runtime.

| One active product, Low normal | **−230.531 µs / −5.938%** | **−242.906 µs / −7.038%** | Repeated negative-control failure |

The primary gate required at least 10% **and** 500 µs mean savings in each process for both dense contexts, positive paired median, and positive savings in both actual callback-order strata. A repeated unchanged-control mean regression exceeding both 3% and 100 µs vetoed retention. All warmups, callback-order strata, tails and measured/all-frame p95 values remain in the [withdrawal review](review.json); no failed subset was used to rescue the result.

The intentionally changed art did pass the bounded captured-scene review. Root viewed ten PNGs; Gameplay viewed sixteen spanning one/six products, mixed phases, partial retirement, the final active survivor, reduced effects, cooling/expiry, actual flight and separate owners. Six products retained a visibly hotter footprint than one; continuing and fading threat remained distinguishable in these captures. This does not establish exact stack-count perception, continuous-motion clarity, physical-input usability or player feel. A visual pass cannot override the failed cost gate.

The candidate omitted only earlier matching **active** flames and two crown strokes at Low detail. Every product fill and boundary remained; forming and cooling marks, independent owner/danger/intensity/geometry distinctions and Standard detail stayed intact. Cohorts were rebuilt call-locally, retaining the final representative's original position and seed. Product damage pools and lifetimes were never combined. Independent paid snapshots, actor context and an actual projectile were preserved. Changed interior pixels were intentional; unchanged contexts and pixels outside eligible polygons remained exact.

The complete run is CPU-side submission of frozen paid scenes, not whole-game cadence, thread CPU, GPU/present time or portable FPS. Ground projection, candidate guards and grouping are inside the whole-ground clock. Packet/state/pixel proof and actual body/projectile context are outside. One untimed bundle inspection follows each first paired draw; shared caches persist, so first/final screenshots are not uniformly cold. The precise [plan](inputs/PLAN.md) preceded measurement.

Three fixture failures remain intact:

- [Generated-source parse failure](failures/parse-generation-failed-a/manifest.json): literal escaped indentation in the generator; no native rendering.
- [Forward-a body admission](failures/body-context-failed-a/manifest.json): 6,302 checks, zero rendered cases; the helper queried nonexistent metadata keys. The repair used the existing `fullbody_art`, `pixel_body_pilot` and `visual_mode` contract.
- [Forward-b context failure](failures/projectile-context-failed-b/manifest.json): 6,952 checks and four completed cases before a combined context assertion. Its receipt did not identify the individual false clause. Source inspection found the omitted production expanded-projectile dispatch; the repair restored configured Foundation-first/owner dispatch before Court fallback, outside ground clocks. The complete retry records actual dispatch counts and keeps strict body/projectile/authority checks. No partial performance subset from this failed run is accepted.
