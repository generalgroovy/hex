Canonical runtime is unchanged. `candidate_hud.gd` overrides only the current HUD's resource drawing method: it omits the lower idle character name and preserves the exact existing protection text call. The top identity and spectator `WATCHING` cue, portrait, resource bars, quantities, inspection, and reserved warning row remain unchanged. This does not reduce panel area and makes no performance claim.

This is an offscreen native HUD contract comparison. It does not boot Bootstrap, perform spectator navigation, simulate physical input, measure performance, prove modal overlap or 200% layout, or qualify human comprehension. The finite Evade sequence uses ordinary commands; no mid-route clock, resource, or protection injection is permitted.

Primary design precedent: Blizzard's [Diablo II: Resurrected Technical Alpha Learnings](https://news.blizzard.com/en-gb/article/23695734/technical-alpha-learnings) removed persistent repetition from the item-comparison prompt after clutter feedback while retaining comparison access. Its [World of Warcraft HUD revision](https://news.blizzard.com/en-us/article/23841481/world-of-warcraft-dragonflight-hud-and-ui-revamp) prioritizes health/action visibility and reduced clutter. These support subtracting duplicated non-actionable information; they do not establish H.E.X.'s exact placement, justify a new toggle, or imply a rendering speedup.
