# Current paid-ground boundary attribution — ignored diagnostic

This is an attribution probe, not an optimization. Root alone may parse/run it
after the canonical runtime is coherent and frozen. No engine run is claimed.

`compare-ground-boundary.gd` compares plain current `HexCourtPresenter` with
`observed_court.gd`. The observed subclass delegates all behavior and records
fixed scalar method clocks. Only `_submit_outline` is copied to separate the
existing mesh lookup and RenderingServer command. Startup checks remove exactly
the declared observer lines and require the remaining method to equal the
preserved/current production source. Existing masks, triangle points, meshes,
overflow fallback, counters, painter order and RID ownership are unchanged.

Example arguments for root's native wrapper:

```text
--path C:/Users/sende/Projects/hex --script res://.godot/iteration-20261013/ground-boundary/compare-ground-boundary.gd -- --no-lan-discovery --output=res://.godot/iteration-20261013/ground-boundary/runs/probe-forward-a
```

Use a second fresh process/output with `--reverse-order`. Do not infer native
success from parsing. Both receipts, empty stderr, watched source equality and
representative native images are separate gates.

The fixture prepares actual campus/Oh Tipi worlds and legal starting loadouts.
After preparation only ordinary finite commands advance authority: one Fire
through natural expiry and paid re-entry, twelve Fire attempts, twelve all-six
Mantle attempts, and two friendly actual owners firing toward separate nearby
ground. No resource refill, manufactured phase, authority clock or status edit
occurs during a route. Refusals remain outcomes, especially for Mantle. Required
phases/owners must actually appear or the run fails. Complete strict snapshots
are captured at successful paid boundaries and restored into fresh concrete
campus worlds for drawing. Restored events are not injected; drawing preserves
the restored packet and its existing events.

There are 12 timed states (six paid states × normal/reduced), each with 32
measured and four separately recorded warmup pairs, plus 10 pixel-only phase,
expiry/re-entry and translated/zoomed controls. Two 640×480 SubViewports and
44 PNGs are bounded. Actual draw callback order and exactly one callback per
arm are asserted. First/final exact RGBA, native material admission, nonblank
paid fields, cache counters and authority equality are required. The same
presenters persist across cases; actual build/hit deltas identify admission
versus retained work. “First” does not mean universally cold.

Whole-ground clocks include production `_prepare_draw_bundle`; content/world
construction, snapshot restore, metadata/coverage, state/packet hashes, cache
reads, source checks, image readback and JSON stay outside. Bundle, topology
and outline are distinct children of whole-ground. Prefix is nested within
topology/mask; mask/points/submit are nested in outline; mesh/command are nested
in submit. Never sum parents and children. Instrumentation increases observed
cost; report plain/observed differences and actual-order strata. Shared court
geometry and native resource state can still create order effects.

This does not measure a full game frame, GPU execution, present latency, actual
foreground FPS, physical input or human readability. It does not prove another
cache would help. If boundary work is small, stop this line of optimization.
Riot's [clarity account](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/)
supports preserving visible gameplay boundaries; it supplies no H.E.X. cost
estimate. Later candidates need separate exact-pixel and integrated gates.

Output is allowed only under a fresh owned `runs/probe-*` directory. Rejected
paths cannot receive a receipt. Failure keeps completed evidence. A 240-second
watchdog bounds asynchronous waits; route loops are independently bounded.
