# Proposed remap hints: bounded native fit gate

`capture-remap-hint-fit.gd` loads the exact frozen unapplied controller/navigation
files. Root alone parses/runs it. No result is claimed before the actual receipt.

The twelve contexts are 960×540 and 1280×720, 100% and 200% text, and keyboard
defaults / supported F5+F6 gameplay remaps / controller prompts. Each captures
the first non-practice menu page, the page containing Developer tools, and the
guide's Range instruction: 36 native PNGs. The guide's active/step fields are
explicitly prepared visual state, not simulated tutorial completion. The
supported editor writes only the fixture's preference object; this does not
dispatch input, alter InputMap, or save.

The fixture calls actual proposed draw/geometry functions and the production
Bootstrap static scale function. It records logical/physical dimensions, actual
menu rows, label/hint widths, wrapping, and the existing pointer/page rectangles.
It requires default strings to match the pinned predecessor and all current
canonical files to remain equal to the patch's predecessor. Controller hint ink
suppression remains the existing draw policy. Draws must preserve world state.

The native boards are offscreen SubViewports in a real rendering process. They
do not boot Bootstrap, exercise key routing, progress through a paid guide, or
measure performance, listening, focus or physical-device usability. The separate
regression draft owns supported remap/input/payment agreement. Fixed wide
Developer/Range status overlays and the challenge footer are excluded from this
menu/guide scope; their fixed y positions must not be advertised as compact 200%
layout acceptance.

The output must be a fresh direct child `runs/fit-*`; all writes require fresh
directory authorization. The 120-second watchdog, source hash recheck, native
node release, mouse invariant/restoration and exact JSON readback apply on every
finish path. No profile is read or written. A root wrapper should separately
reject stderr, require normal termination, verify the declared 12 contexts and
36 PNG hashes, and preserve any failed run rather than reuse its output folder.

Example root-owned arguments (not executed by this agent):

```text
--path <repo> --script res://.godot/iteration-20261013/remap-guide-hints/capture-remap-hint-fit.gd -- --no-lan-discovery --output=res://.godot/iteration-20261013/remap-guide-hints/runs/fit-a
```

An image being nonblank is only an execution check. Actual font-width, wrapped
body spacing and panel bounds are independently checked and reported; root and
Experience must still inspect representative native images before acceptance.
