## Internet friend play acceptance slices

User decision: different homes, simplest normal-game experience. The target is
Open H.E.X. -> Create room -> Copy code -> friend joins. Friends should not need
Godot, a VPN, an account, a terminal, manual IP addresses or router changes.
This is a target, not a feature claim for the current portable.

Historical September 30 captures took 353-380ms, and the full local lifecycle
failed its 120-second deadline. E6 ownership and current E7/E8 collision/decoder
work address that local CPU dependency. The latest measured capture is
28.863-74.108ms across four cases. The complete current packaged localhost
lifecycle passes in 74.955 seconds, all stderr empty. A relay cannot repair a
local CPU bottleneck. Keep the verified
portable available and do not infer physical internet acceptance from localhost.
