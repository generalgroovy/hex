## Bounded optimization

Fresh attribution identified repeated edge string construction and inward
triangle construction inside active/retained-coverage field drawing. This slice
reuses only those exact geometric results, not a whole rendered frame or effect
state. The previously deferred viewport-culling prototype remains unintegrated:
its recorded dense-scene regression is not solved by selecting a favorable scene.

| Reused | Still evaluated every draw |
|---|---|
| Six coordinate-only edge suffixes per exact fixed polygon | Material, owner, phase, danger; legacy footprint, intensity and expiry |
| Exact inward triangle points per display polygon and stroke width | Current neighbor counts and which borders remain exposed |
| Three production widths: 1, 2 and 2.5 px | Color, opacity, animation frame and all visible material marks |

Each cache holds at most 512 polygons with FIFO eviction. Keys are detached from
caller-owned packed arrays; returned string/vector arrays are recursively
read-only. Arbitrary diagnostic stroke widths are calculated but never cached.
All caches reset on successful or failed presentation reconfiguration. Drawing
submits the same triangles in the same order with the same native primitive API.

No simulation, chemistry, movement, character, input, hitbox, camera, networking
or balance change. Formation and decay still render even at zero active quantity.
Coverage remains exact, stationary whole-hex authority; no trails are introduced.
