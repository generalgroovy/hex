# FLUX 2 runtime visual assets

The versioned runtime visual foundation is indexed by
`content/visual/visual_asset_registry_v1.json` and documented in
`docs/VISUAL-ASSET-PRODUCTION.md`.

Key locations:

- `sprites/skeletons/` — canonical five-size animation foundation;
- `sprites/champions/nico_lai/` — first integrated champion candidate;
- `tiles/sanctum/` — modular 16×16 environment kit;
- `tiles/materials/` — foundation material presentation;
- `maps/sanctum/` — first gameplay-scale visual slice;
- `icons/` — element, ability and application-state atlases.

Concept boards remain separate under `assets/concept/` and are not runtime authority.
