# Champion visual packages v2 (legacy archive)

These packages are retained for migration and provenance only. The active
runtime uses the body/clothing-only v3 foundation atlas and exactly three body
types: `small`, `middle`, and `large`; legacy Tiny/Medium/Huge labels map to
Small/Middle/Large and must not be exposed by new selectors. Spells, auras,
shadows, environment and equipment are separate layers.
