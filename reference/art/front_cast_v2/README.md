## Shared proportion contract

| Area | Review target |
|---|---|
| Body roles | Preserve current Small/Middle/Large catalog membership |
| Relative stature | 58:68:76, approximately85%:100%:112%, from current body_type_profiles_v1.json; concept comparison target, not a measurement claim |
| Measurement | Soles to anatomical cranial crown; exclude horns, hair, fins, crown and wings |
| Camera | Same orthographic front camera, scale, canvas and foot baseline; never independently enlarge small characters to fill their cards |
| Adult anatomy | Approximately6-7 skull-heads tall; plausible joints, limb lengths, hands and feet; no baby/chibi proportions |
| Species | Express identity through anatomy, build, face, material and costume; not arbitrary head inflation |
| Separation | Hands empty; no weapons, magic, aura, floor or environment merged with body |
| Background | Neutral parchment and detached captions for review, not verified transparent runtime sprites |
| Acceptance | Compare alongside the scale reference; generated raster proposals still require measured normalization and animation production before import |

The existing runtime recipe head-ratio validator is a separate legacy visual contract; this proposal does not silently alter it.
