a practice space, not a requirement to memorize the whole catalog.

trail. Non-burning ingredient matter is harmless; active Fire and active reaction
layers apply their authored effects.

Each cast owns one finite budget partitioned across its flight, optional trail and
ground matter. Direct contacts subtract exact strength. Eligible overlapping
matter consumes only the matched portions, so unmatched live portions remain
available until they react, are intercepted or expire. Different casts can
combine; one source cannot react with itself, and trail + trail never reacts. A
new terminal can combine with an older trail for a shorter sustained reaction.
Capacity admission is atomic: a refused product does not spend Flux or matter.

Sustained active windows are about 25% longer, allowing more pulses if you remain
inside a damaging hazard. The five instant reactions retain their short windows;
