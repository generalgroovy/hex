## Output status vocabulary

`STATIC_VERIFIED`: check of supplied bytes, authored data or independent geometry under documented assumptions. `PROPOSAL`: new design or experimental candidate, not accepted into the game. `OFFLINE_PREVIEW`: a generated diagram, composition or browser mock, not a screenshot of an implementation. `SCHEMATIC`: future topology without verified world placement. `SOURCE_SNAPSHOT`: original input bytes copied for reference. `REJECTED`: prior failed draft kept as evidence. `NOT_RUN`: a named test that was not executed. `PENDING`: human/release decision not yet made.

Source pointers and line references are reproducible citations inside this package, not links to an assumed newer remote repository. Any replacement source must be rechecked and rehashed before integration.
