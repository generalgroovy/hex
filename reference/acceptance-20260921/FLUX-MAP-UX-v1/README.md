# FLUX / MAP + UX v1

**A source-anchored courtyard design and reversible pilot. Not a runnable game or accepted Godot patch.**

Start with [HANDOFF.md](HANDOFF.md). For visual review, open [preview/index.html](preview/index.html) after extracting the complete archive. It includes the plans, native normal/reduced compositions, chemistry matrix and clearly mocked Company interactions. All preview dependencies are local; no server or account is part of the design prototype.

| Read / inspect | Purpose |
|---|---|
| [LAYOUT.md](LAYOUT.md) and [HEX_LAYOUT.json](HEX_LAYOUT.json) | Current geometry, proposed courtyard, exact units/anchors, collision semantics and future schematic boundaries |
| [UX_TABLES.md](UX_TABLES.md) | HUD, modifier layers, source-derived reaction table, station permissions and first five minutes |
| [ACCEPTANCE.md](ACCEPTANCE.md) | Executed offline evidence versus unexecuted traversal, clearance, readability, player and multiplayer tests |
| [INTEGRATION.md](INTEGRATION.md) | Hash-gated candidate/rollback, owners, constraints, missing inputs and budget gates |
| [SOURCE_REFERENCES.md](SOURCE_REFERENCES.md) | Cited paths/line ranges/JSON fields and status vocabulary |
| `artifacts/` | Actual PNG/SVG plans, annotated gameplay capture, native compositions, terrain kit and reference screenshot |
| `pilot/` | Separate candidate JSON, exact-source forward/reverse patches and hash contract |
| `evidence/` | Input integrity, original captures/source extracts, rejected first draft and executed check reports |
| `tools/` | Optional reproducible geometry, candidate creation, rendering and browser checks; no automatic live integration |

A diagram is not a gameplay capture. A native composition is not a runtime sequence. A mock acknowledgement is not a network result. Source topology is not concept-map geometry. Those distinctions are retained in the artifacts and manifest.
