# Named cast directional part generation

Built-in image generation, transparent RGBA. `styleref1.png` supplies crisp rich
pixel material/style; the current 30-character catalog and cast sheet supply
identity. Historical text/affinities/weapons on the style image are ignored.
Six independently generated sheets each contain five named identities and eight
head directions. Originals are preserved in `../reference/` and exact prompts
are saved beside this file. These component sheets are not complete animations.
