# Oh Tipi cardinal core source prompt

Status: initial built-in image generation prompt; output not yet reviewed.

Use case: stylized-concept.
Asset type: production pixel-art character sprite source sheet, not a poster.
Input image: the original Oh Tipi is the authoritative anatomy, clothing,
palette and pixel-shading reference. Its staff, magic, aura and ground shadow
are not part of the body sprite and must be omitted.

Create exactly sixteen separate full-body sprites of the same Oh Tipi on a
genuinely transparent background, in a strict four-column by four-row square
grid. Equal cells, generous transparent gutters, no text, labels, borders,
checkerboard, scenery, lighting effects or decorative objects.

Every column has one fixed facing: column1 front/south, symmetrically toward the
camera; column2 right/east true profile; column3 north/back with no visible face;
column4 left/west true profile. Screen-cardinal top-down game view, approximately
55-degree art elevation; no rotated/isometric ground axes.

Every row has one action: row1 relaxed ready stance with empty hands; row2 compact
airborne knees-bent jump pose; row3 active empty-hand spell release reaching in
that column's facing direction, without any spell effect; row4 small balanced
hit recoil facing the same direction. Draw all sixteen distinct correct poses.

Preserve teal Seakin anatomy, elongated layered fin crown, small ivory face and
restrained eyes, teal scales, navy/plum layered coat, ivory tabard, warm brass
fasteners and small red cloth details. More anatomical than chibi: a small head
relative to torso and limbs, sensible arms and hands, balanced body. Simplify
tiny costume ornaments into clean readable pixel clusters for a 68px-tall game
sprite. Keep head, torso, limb mass and clothing lengths identical across poses;
do not grow the character in jump/cast rows. Do not copy or mirror asymmetric
costume details into the wrong anatomical side. Entire body and fin tips visible
inside every cell, consistent drawing scale, nearest/pixel edges rather than
smooth vector gradients or blur. No weapons, staffs, wands, focus props, auras,
magic, particles, shadows, names or text.
