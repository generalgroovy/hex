# Seakin directional head-parts source

Built-in image generation; supplied styleref1 and current 30-cast image are style
references, not editable targets or sources of current roster/affinity rules.

Create one transparent pixel-art production parts atlas for H.E.X., not a poster.
Exactly 8 equally spaced columns and 3 equally spaced rows, 24 isolated Seakin
heads/short necks, each in its own cell, no body or overlapping pieces. Columns
are S(front), SE(front-right45), E(right90), NE(rear-right135), N(back180),
NW(rear-left225), W(left270), SW(front-left315). Faces rotate in anatomical yaw,
not in-plane rotation. Rear views have no eyes or facial features. The same
compact biped aquatic-dragon species, blue scales, cheek fins, dark navy crown
spines, pale turquoise lower jaw, small gold eyes; expressive friendly fierceness.
Rows are neutral, masculine, feminine appearance options; subtle fin/hairline/
face detail distinctions, same skull envelope and no exaggeration. No assumed
canonical character gender. Preserve head identity across eight facings.

Style: charming crisp oldschool fantasy pixel sprites matching Oh Tipi in the
style references; dark colored contours, broad 3-tone material clusters, clean
stepped pixel edges, no antialias blur or smooth Flash/vector gradients. Aim for
recognizable silhouettes when reduced to roughly16–20 pixels high. Approximately
4–4.5 heads tall once attached to the existing body. Pixel art, not realistic
painting. Keep each head upright with short neck at consistent base height.
Center each head with generous transparent gutters, same head scale across all
24 cells. Absolutely no labels, numbers, frames, parchment, shadows, magic,
weapons, water splashes, particles, glow or background/checkerboard pixels.
Actual transparent alpha outside artwork. This raster will be measured/cropped,
then assembled onto existing rig poses; no new gameplay geometry.
